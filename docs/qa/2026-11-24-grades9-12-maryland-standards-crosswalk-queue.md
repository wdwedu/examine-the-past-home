## Grade 11 alignment build · November 24, 2026

Units 11.8–11.10 now link 12 lesson objectives to 11 specific objectives in the [June 2025 Maryland Modern World History Framework](https://msde.maryland.gov/media/17929). The links below open the relevant framework page. Each lesson has a matching student task in Closure and a description of what a successful response includes. The three unit assessments add a focused written argument and guidance for reviewing it.

The framework expects several named places, people and events. Each row identifies the portion this lesson teaches. Topics or cases outside the row remain part of the course-level coverage review. In particular, the postwar independence objective still needs an explicit Ben Bella and Algeria assessment, and the Germany case in the fascism lesson cannot stand in for the other four countries named under MWH.3.5.a.

## Indicator-level signoff protocol
1. Record the specific, current Maryland high-school framework/standard code and exact indicator text; do not infer a code from a course title.
2. Identify which lesson objective teaches the indicator and which assessment item or performance task proves it.
3. Check course placement: Grade 12 electives do not automatically share an official statewide Grade 12 elective framework; use relevant economics, geography, civics, history or local course requirements as appropriate.
4. Confirm reading accommodations, alternative access, multilingual needs and evidence of independent comprehension.
5. Mark verified only when the state framework and assessment evidence have both been inspected. An automated domain guess never satisfies this step.
